# Instructions

## Local build

```bash
npm install
npm run build
```

## Local test

```bash
npm run dev
```

Open <http://localhost:4321> in a browser. Press `Ctrl+C` to stop the server.

## Update to remote

```bash
git status
git add .
git commit -m "Update website"
git push origin main
```

Pushing to `main` automatically deploys the website through GitHub Pages.
